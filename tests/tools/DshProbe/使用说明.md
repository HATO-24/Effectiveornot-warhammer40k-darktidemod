# DshProbe 使用说明

一个模组搞定两件事：**导出模拟器还缺的游戏内数据** + **记录伤害**。

---

## 一、装好之后怎么用

### 1. 重启游戏

模组已经注册进 `mod_load_order.txt`，**重启一次游戏**即可加载。

> 旧的 `DshDamageLog` 已在加载顺序里注释掉（它和 DshProbe 写同一个伤害日志文件，
> 两个一起跑会把行交错）。它的文件夹可以删掉。

### 2. 进游戏后，在聊天框输入命令

命令是**聊天框**里输入（不是控制台）。按回车进入聊天，输入 `/dshprobe` 再回车。

| 命令 | 作用 | 耗时 |
|---|---|---|
| **`/dshprobe core`** | **只导关键数据（先跑这个）** | 几秒 |
| `/dshprobe` | 全量导出（含次要数据） | 十几秒 |
| `/dshprobe list` | 列出会导哪些模块 | 瞬间 |
| `/dshprobe status` | 看当前进度 | 瞬间 |

**建议顺序：先进一次任务/灵能室，再输入 `/dshprobe core`。**
（在主界面也能跑，但有些表要进任务后才被加载。）

跑完会看到屏幕提示 `DshProbe: 6/6 完成`。

### 3. 导出结果在哪

```
Warhammer 40,000 DARKTIDE\mods\DshProbe\out\
├── breeds.json                     ← 敌人部位倍率与护甲（最需要）
├── damage_profile_templates.json   ← 全武器伤害档
├── weapon_trait_templates.json     ← 祝福定义
├── archetype_talents.json          ← 天赋官方名
├── weapon_archetypes.json          ← 武器归属哪个角色
├── weapon_traits_all.json          ← 所有祝福（按武器族合并）
├── armor_settings.json
├── power_level_settings.json
├── damage_settings.json
├── buff_templates.json
├── talent_settings.json
└── minion_damage_profiles.json
```

进度和失败原因写在 `mods\DshProbe\dsh_probe.log`。
**如果某个文件没生成，把那个 log 发我。**

不需要你分析，我来解析。

## 二、伤害记录（第二部分）

导数据不需要打架；**伤害记录**才需要。

| 命令 | 作用 |
|---|---|
| `/dshlog` | 开关伤害记录 |
| `/dshmark 文字` | 给接下来这段打标记（如 `/dshmark 轻击-头-无甲`） |
| `/dshnew` | 开新文件（每次测试前敲一下） |

输出：`mods\DshDamageLog\damage_log.jsonl`（一行一条，崩溃不丢）。

## 三、我具体还需要什么（按重要性）

> **重要：下面 1~5 项都不需要你拥有对应角色或武器** —— 它们是从游戏文件里读的数据表，
> 只要游戏在跑就能导出来。只有第 6 项（实测伤害）才需要你实际拿到那把武器。

### 1. 敌人部位数据（最需要）★

**为什么缺**：打击部位倍率在 `breed.hitzone_damage_multiplier[攻击类型][部位]`，
而反编译源码里 `breeds.lua` 只是个聚合器，真实 breed 文件不在我这。
所以我现在**把打击部位倍率简化成了固定 1**，这是"打头比打身体伤害高"那类问题的根源。

**需要**：`/dshprobe core` 生成的 `breeds.json`

**具体要解决的问题**：重锤兵（`renegade_executor`）的头是甲壳、身体是 Flak，
我需要它每个部位的真实倍率和护甲，才能判断"头 > 身体"到底对不对。

### 2. 全武器伤害档（补最后 4%）★

**为什么缺**：我的反编译源码缺了 36 个武器族的 `settings_templates/` 目录。
我已经从 GitHub 补齐了 91 个文件（覆盖率 421→601 档），但 GitHub 那版可能和我游戏版本不一致。

**需要**：`damage_profile_templates.json`

**要解决的问题**：重型开膛剑（说明 600/1080 vs 我的每段 150~350，差 3.6~4 倍）、
动力剑、霰弹枪这几条对不上。

### 3. 链锯武器的伤害段数 ★

**为什么缺**：开膛剑说明里的 600/1080 很可能算的是**整次攻击总和**，而 profile 是**每段**。
要知道段数才能验证。

**需要**：`damage_profile_templates.json` 里链锯档的 `damage_interval` / `num_ticks`
一类的字段（如果表里没有，就退化成第 6 项的实测）。

### 4. 祝福→官方名的映射 ★

**为什么缺**：`loc_trait_bespoke_*` 的键名是**语义名**（`allow_hipfire_while_sprinting`），
不是从 trait 名机械推导的（`..._autogun_p1_hipfire_while_sprinting`）。
我用语义匹配补了 107 个，**还剩 67 个没官方名**。

**需要**：`weapon_trait_templates.json` + `weapon_traits_all.json`
（运行时表里可能带 `display_name`，源码里没有）

### 5. 武器→角色归属

**为什么缺**：我从一次实时抓取拿到过，但没抓全。
你说你没有所有角色 —— **没关系，这个不需要你拥有角色**，
`weapon_archetypes.json` 是配置表，直接能读。

### 6. 实测伤害（只有这项需要你真的拿到武器）

**不需要开新档**：训练场（灵能室）就行。

| 优先级 | 测什么 | 怎么测 |
|---|---|---|
| 高 | **头部 vs 身体**（验证第 1 项） | `/dshnew` → `/dshmark 身体` 打身体 10 次 → `/dshmark 头` 打头 10 次。**选你有的任意近战武器** |
| 高 | **链锯段数**（验证第 3 项） | 有开膛剑/链锯斧的话：`/dshnew` → 一次重击，打完等结算完 → `/dshmark` 记一下 |
| 中 | **霰弹枪总伤 vs 单发** | 有战斗霰弹枪的话：对着墙/敌人开一枪 |
| 中 | **多段 DoT 曲线**（已有流血，缺燃烧） | 有喷火器的话：挂燃烧后**停手**，等它衰减到 0 |

**每一项都要 `/dshnew` 重开一次**，我按文件分析。

## 四、出问题了怎么办

| 现象 | 原因与处理 |
|---|---|
| 输入命令没反应 | 命令要在**聊天框**（回车打开）里输入；确认模组在 `mod_load_order.txt` 里且未被注释 |
| 提示 `unknown command` | 模组没加载 → 检查 `mods\DshProbe\DshProbe.mod` 是否存在 |
| 某个 json 没生成 | 看 `mods\DshProbe\dsh_probe.log`：`FAILED xxx` 是模块没找到，`CANNOT WRITE xxx` 是目录不可写（现已回退到 `mods\DshProbe\` 根目录）。把 log 发我 |
| 游戏卡顿 | 正常，导出分帧进行；`core` 比全量快很多 |
| json 文件很大（>50MB） | 正常（`minion_damage_profiles` 可能很大），发我时压缩一下即可 |
| 想重跑 | 再输入一次 `/dshprobe core` 会覆盖 |

## 五、文件太长发不过来怎么办

`out\` 里如果某个文件特别大，只需要发这几个小的（最关键）：
`breeds.json`、`weapon_archetypes.json`、`weapon_trait_templates.json`、
`archetype_talents.json`。

大的（`minion_damage_profiles.json`、`buff_templates.json`）可以跳过。
